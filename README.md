# High-Volume Particle-into-Liquid Sampler (Hi-Vol PILS)

Skripte und Messdaten aus der Bachelorarbeit „Entwicklung eines neuartigen Hi-Vol PILS" (RIQAP, FHNW / Universität Basel).

## Struktur

- `acquisition/` – GUI-Logger (CPC, OPC-N2, TC-08)
- `analysis/` – Aktivierungskurven, Tröpfchengrössen, Baseline
- `utils/` – Mie-Korrektur OPC-N2, SMPS-Auswertung
- `data/` – Rohmessungen (NaCl, Russ), `data/baseline/` – Untergrund
